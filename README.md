## Features & Benefits

- **No Ads**: Entirely ad-free experience.
- **No Trackers or Analytics**: Zero data collection, telemetry, or third-party SDKs.
- **Offline First**: Runs completely offline without internet permissions.
- **Infinite Levels**: Procedurally generated levels with customizable grid sizes and difficulty levels.
